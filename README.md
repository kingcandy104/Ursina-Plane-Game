# ✈️ Airplane Coin Collector Game

A simple 3D endless runner-style game built with the **Ursina Engine** in Python.  
Fly your airplane, collect coins, avoid obstacles, and see how far you can go before crashing!

---

## 🎮 Features
- Player-controlled airplane with wings and tail
- Smooth movement using arrow keys or WASD
- Coins to collect (+10 points each)
- Obstacles (cubes, spheres, pyramids) to avoid
- Endless scrolling ground for continuous gameplay
- Score and distance tracking displayed on screen
- Game Over screen with restart option
- Simple UI instructions that fade after 5 seconds

---

## 🕹️ Controls
- **Move Left:** ← or `A`  
- **Move Right:** → or `D`  
- **Move Up:** ↑ or `W`  
- **Move Down:** ↓ or `S`  
- **Restart Game:** `R` (after Game Over)  
- **Exit Game:** `ESC`  

---

- Python 3.8+  
- [Ursina Engine](https://www.ursinaengine.org/)
